# 제품 비전 — 나를 찾는 추억여행 by1998

## 한 문장
1998년 한국의 동네로 시간여행해 그때의 방·골목·문방구·음악·놀이를 경험하며, 어린 시절의 나와 지금의 나를 발견하는 따뜻한 3D 안식처.

> “너다운 게 가장 좋아. 아무것도 잘하지 못해도 너는 소중한 사람이야.”

## 핵심 루프
놀이가 기억을 깨우고 → 기억이 대화로 이어지고 → 대화가 물건에 남는다.

## 정체성 원칙
- 브랜드는 ‘나를 찾는 추억여행 by1998’. ‘나답다’는 그 안의 자기발견 축이며 앱의 이름이나 유일한 기능이 아니다.
- 고무줄놀이는 여러 놀이 중 **첫 번째** 미니게임이다.
- 치료·진단을 약속하지 않는다. 휴식·자기돌봄·기억 탐색 체험.
- 경쟁·등급·탈락·좋아요/친구 수 비교·일일 접속 압박·유료 보상 강요 없음. 접속하지 않았다고 어린 나가 슬퍼하거나 죄책감을 주지 않는다.
- 아픈 기억을 요구하지 않는다. 과거가 불편하면 상상 속 방으로 바로 시작할 수 있다.

## 경험 구성
1. **골목(1998)**: 실제 3D 공간을 걸어 다니며 집·문방구·공터로 이동. 모든 방문은 공간 속 위치와 물건으로 연결된다.
2. **놀이**: 고무줄놀이부터. 실패는 균형을 잡고 다시 하는 것. 실력은 보이되 자기 가치를 수치로 평가하지 않는다. 이후 땅따먹기·팽이치기·구슬치기·공기놀이·딱지치기.
3. **어린 나와의 대화**: 공감 → 판단 없는 질문 하나 → 어린 나에게 해줄 말 → 지금의 나에게도? → 물건에 저장. 언제든 조용히 끝낼 수 있다. 상담사를 사칭하지 않고, 위기 표현에는 사람의 도움을 먼저 안내한다.
4. **나의 방**: 실제로 가졌던 방 / 갖고 싶었던 방 / 상상 속 방. 소품을 고르고 놓고, 물건마다 기억과 말을 담는다. 첫 소품은 무료이며 꾸미기를 회복의 유료 조건으로 만들지 않는다.
5. **세계의 3단계 변화(강제 해금 없음)**: 기억의 방 → 관심이 쌓이는 방 → 나다운 세계(정원·동네 확장).
6. **함께 놀기(선택)**: 정해진 손짓만, NPC는 NPC로 표시, 개인방·대화·사진·음성은 타인에게 노출되지 않음. 미성년자-성인 무작위 매칭 금지, 신고·차단·나가기.

## 미술 방향
따뜻하고 사실감 있는 stylized 3D. 1990년대 말 저층 주택가, 방범창, 옥상 물탱크, 철제 대문, 전봇대와 전선, 문방구, 장판과 꽃무늬 커튼, 브라운관 TV와 카세트. 실제 브랜드·곡·앨범 아트는 권리 확인 후에만.

## 개인정보·안전
최소 수집, 기본 로컬 저장, 서버 전송 전 명시적 동의, 편집·삭제 가능. 사적인 내용은 공개 공간과 매칭에 쓰지 않는다. 인격 유형·트라우마·애착 유형을 진단하지 않는다.
