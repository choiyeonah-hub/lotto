## 알려진 제약
- 캐릭터는 코드로 만든 관절 모델(리깅 GLB 아님). 얼굴 표정 없음.
- 게임 시간은 프레임당 0.1초로 제한 — 매우 느린 기기에선 슬로모션처럼 보인다.
- 밟기·걸기는 줄이 앞쪽 약 1m 이내에 있어야 닿는다(닿지 않으면 안내 자막).
